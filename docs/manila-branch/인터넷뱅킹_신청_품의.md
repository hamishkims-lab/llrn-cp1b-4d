# 필리핀 마닐라 지사 은행계좌 인터넷뱅킹 신청의 건

필리핀 마닐라 지사의 원활한 자금 집행을 위해 보유 중인 계좌의 인터넷뱅킹을 신청하고자 하오니, 업무에 참고하여 주시기 바랍니다.

== 아 래 ==

## 1. 업무 내용

: 필리핀 마닐라 지사 은행계좌(PHP, USD) 인터넷뱅킹 신청의 건

## 2. 요청 사유

: LLRN 프로젝트 수주 전 비용(직원 인건비, 용역비 등)을 집행하기 위해 계좌를 개설하여 수기로 집행하고 있음. 그러나 수주가 지연되면서 사인권자가 집행 때마다 현지로 출장을 가야 하는 상황이므로, 업무 효율화와 출장비 절감을 위해 인터넷뱅킹을 신청하고자 함.

: LLRN 프로젝트 수주 후 한국 직원이 현지에 파견될 때까지 인터넷뱅킹으로 집행 업무를 수행할 예정임. 인터넷뱅킹도 다단계 결재선을 적용하므로 기존 수기 집행(POA 2인 서명)과 동일한 수준의 통제 절차가 유지됨.

※ 계좌번호는 공개 저장소이므로 생략함 (내부 품의 시 기재).

## 4. 인터넷뱅킹 운영 체계 (하나은행 마닐라지점 확인 사항)

### 1) 계정 구성

- 은행이 관리자(Admin) 계정 1개를 생성하여 당사에 제공함.
- 당사는 관리자 계정으로 등록자, 결재자, 승인자 계정을 직접 생성함. 사용자 간 결재 라인도 관리자 계정에서 설정함.

### 2) 사용자별 권한 및 인증 방식

| 구분 | 역할 | 인증 방식 |
|---|---|---|
| 관리자 | 사용자 계정 생성, 결재 라인 설정 | ID/PW + 인증서 |
| 등록자 | 이체 건 입력(기안) | ID/PW |
| 결재자 | 등록 건 검토 및 1차 결재 | ID/PW |
| 승인자 | 최종 승인(은행 실행) | ID/PW + 인증서 |

※ 은행 규정상 관리자가 승인자를 겸할 수 있음.

### 3) 집행 절차

① 등록자가 증빙(인보이스, 급여대장 등)을 근거로 이체 건을 등록함
→ ② 결재자가 내용과 증빙을 검토한 후 결재함
→ ③ 승인자가 인증서로 최종 승인함
→ ④ 은행이 이체를 실행함

### 4) 신청 서류

: 기존에 하나은행이 당사 담당자에게 안내한 서류와 동일함.

## 5. 수기 집행과 인터넷뱅킹 절차 비교

| 구분 | 수기 집행 (현행) | 인터넷뱅킹 (변경) |
|---|---|---|
| 집행 요청 | 현지 담당자가 지급 서류를 작성 | 등록자가 시스템에 이체 건을 등록 |
| 1차 확인 | POA 서명권자 1의 서명 | 결재자의 결재 (ID/PW) |
| 최종 승인 | POA 서명권자 2의 서명 | 승인자의 승인 (ID/PW + 인증서) |
| 통제 수준 | 2인 서명 | 2인 이상 결재 (동일) |
| 서명권자 소재 | 현지 출장 필요 | 국내에서 승인 가능 |
| 집행 이력 | 수기 서류 보관 | 시스템에 전자 기록 자동 보관 |

→ 집행 건마다 2인 이상이 확인하고 승인하는 구조는 기존 POA 2인 서명 방식과 동일함. 서명권자가 출장 없이 국내에서 승인할 수 있다는 점만 달라짐.

## 6. 내부통제 방안

- 결재자와 승인자는 현행 POA 서명권자로 지정하여 기존 권한 체계를 유지함.
- 등록자, 결재자, 승인자는 서로 다른 인원으로 지정하여 직무를 분리함.
- 관리자 계정은 [본사 담당자 / 사인권자]가 관리하며, 사용자 및 결재 라인 변경 시 사전 보고함.
- 인증서는 승인자 본인 PC에만 설치하고 타인과 공유하지 않음.

## 7. 참고 사항

: 하나은행은 해외 인터넷뱅킹 고도화 작업을 거쳐 2027년 말 새로운 서비스를 출시할 예정임. 다만 현행 시스템으로도 다단계 결재선 지정이 가능하므로 요청 거래를 수행하는 데 문제가 없음.
