# 수신함 (inbox)

4단계 Telegram 봇이 현장 회신을 이 폴더에 **한 줄에 메시지 하나(JSON Lines)**로 덧붙여 씁니다. 봇은 이 폴더에만 쓰고, 실적 데이터 파일(`LLRN_CP1B_실적.json`)은 앱만 저장합니다.

앱의 [가상 현장 · 메신저] → **[수신함 파일 읽기]**가 `*.jsonl` 파일을 읽어 검토함에 넣습니다. 이미 읽은 메시지(id 기준)는 다시 넣지 않습니다.

한 줄 형식:

```
{"id":"tg-20280112-0001","at":"2028-01-12T17:35:00+08:00","from":{"id":"c2","name":"R. Santos"},"chat":"dm","text":"P61 파일캡 완료, P62 코핑 50%"}
```

| 항목 | 내용 |
| --- | --- |
| id | 메시지 고유 번호 (봇이 붙임) |
| at | 받은 시각, 현장 시각(+08:00). 07:00 전에 온 회신은 전날 실적으로 처리 |
| from.id | 작업반 id(c1~c5) 또는 Telegram 사용자 번호(작업반 설정의 tg) |
| text | 회신 원문 (번호형 "1. 60%" 또는 자유 문장) |

예시 파일: `_예시_inbox.jsonl.txt` (확장자가 .txt라 앱이 읽지 않음. 이름을 .jsonl로 바꾸면 시험용으로 읽힘)
